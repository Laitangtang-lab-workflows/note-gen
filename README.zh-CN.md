# note-gen

**AI 在环的文献库策管：双区笔记生成（期刊六部分笔记、长篇概览加行号锚点目录）、启发式元数据抽取加 AI 校验、决策树分类、双库布局的脚本化移动、索引对账、基于 Crossref 的引用同步。**

> [!NOTE]
> 本仓**全部内容由 AI 维护**，人类定方向、做决策，详见 [AI 维护声明](#ai-维护声明)。英文说明见 [README.md](README.md)。

## 解决什么问题

文献库不腐坏的条件是每篇文献都有真笔记、真分类、与官方记录一致的引用文件——手工做不缩放，AI 放养做不正。本 skill 按唯一行得通的分工切分：**AI 做理解，脚本做机械**：

- **双区笔记**——期刊文六部分笔记（题、作者、摘要全译、逐节概括、结论、有趣之处）；书籍学位论文 ≤300 字概览加带 fulltext 行号锚点的准确目录（永不通读上万行的书）
- **尽力抽取加强制校验**——启发式抽取器跨 Elsevier、Springer、AIP、OCR 版式拉题名、作者、DOI、年份；每个字段都标记待 AI 校验，已知陷阱文档化（期刊名标题、压平上标、收稿年与出版年）
- **决策树分类**——AI 按各区决策树分类并写可审阅的决策文件；`apply` 把仓内 md 三件套与同步盘 PDF 同路径一起移动、拒绝跨区、干跑预览把关
- **索引对账**——两区各自的 `_index.json` 与文件系统保持一致；每个子命令无状态、幂等
- **带牙齿的引用同步**——每篇 RIS 由 Crossref 再生，并与官方 doi.org RIS 做文件级对照；出现 ❌ 管线即停
- **测试护栏**——抽取器自带自包含回归测试；新失败先沉淀 fixture 再修

## skill 安装

```
git clone https://github.com/Laitangtang-lab-workflows/note-gen ~/.agents/skills/note-gen
```

兼容一切支持 SKILL.md 约定的 agent 框架。需 Node.js；可选的引用同步另需 `reference_materials/` 旁的 `引用信息/脚本/` Python 3.10+ 工具链。同步盘 PDF 库无默认位置——设 `NOTEGEN_PDF_ROOT`（或传 `--pdf-root`）激活 PDF 侧功能。
